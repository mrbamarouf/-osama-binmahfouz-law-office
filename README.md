# Osama Bin Mahfouz Law Office

Premium bilingual website for Osama bin Ahmed bin Salem bin Mahfouz Law Office.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Centralized Arabic and English content
- Static front-end consultation form

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

Set `NEXT_PUBLIC_SITE_URL` to the production domain before publishing so canonical URLs, sitemap entries, and Open Graph metadata point to the final host.
